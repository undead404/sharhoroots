# Нишпорка в цьому проєкті

CLI встановлено через `uv tool install --python 3.12 'nyshporka[app,archives]'` в ізольоване користувацьке середовище. Команда `nysh` доступна в PATH; перевірка версії — `nysh version`.

Робочий простір: `~/Documents/Нишпорка`, поза сховищем Quartz. Для команд із цього репозиторію використовуйте обгортку, яка явно обирає простір:

```sh
sh scripts/nysh.sh info
sh scripts/nysh.sh op workspace.info
sh scripts/nysh.sh doctor --json
sh scripts/nysh.sh catalog list
```

Змінна `NYSHPORKA_WORKSPACE` перевизначає шлях обгортки. Доступ Codex до вибраного простору налаштовано в `.codex/config.toml`; зміна застосовується в новій сесії.

Встановлено набір `catalog`: каталоги й архівні інструменти. Рушії HTR та ваги моделей не встановлено; їх налаштовують окремо перед читанням сканів. Дані справ, скани й результати читання зберігайте в просторі Нишпорки, а не в `content/`. Для цього сховища не запускайте `nysh site build`: сайт збирає Quartz.

Локальні скіли містяться в `.agents/skills/`. Під час ініціалізації Nysh оновлює керовані файли, зберігаючи змінені вручну. Не використовуйте `nysh skills install --force`: проєкт має власні правила. Архівні робочі процеси виконуйте за `AGENTS.md` та відповідним скілом.

Офіційна інструкція: [встановлення Нишпорки](https://nyshporka.online/docs/install/).

## Підказки Супряги перед пошуком

Після перевірки `tasks/`, `sources/` і `books/`, на початку дослідження нового
поселення чи фонду перевіряйте попередні знахідки через `shepit.poshuk`.
Пошук прізвища — лише коли його прямо просить користувач. Перед порадами,
де шукати, отримайте досьє поселення або тематичні підказки:

```sh
sh scripts/nysh.sh share dovidka
sh scripts/nysh.sh share vyklyky --json
sh scripts/nysh.sh share vyklyk shepit.poshuk --param misce="Шаргород" --param oblast="Вінницька" --json
sh scripts/nysh.sh share vyklyk shepit.poshuk --param q="Вінницький повіт ревізія" --json
```

Параметри замінюйте відповідно до питання; значення запитів — українською.
Сервер визначає доступність: перевіряйте `dozvoleno`, не покладайтеся на
збережений перелік можливостей. Досьє — `data.vidpovid.dosie`, тематичні
підказки — `data.vidpovid.pidkazky`. За `stan: choose` попросіть користувача
уточнити поселення серед `kandydaty`, потім повторіть запит з областю.

Записуйте корисні посилання, локатори, запит і межі охоплення в дослідницький
запис. Підказка не замінює джерело: перевіряйте сам документ перед внесенням
тверджень до статей. `zakryto` та інші лічильники не доводять відсутності
документів. Помилка сервісу не зупиняє незалежний пошук. Внески до Супряги
виконуйте за чинною постійною згодою користувача та `share-case`.

Окремий проєкт Нишпорки:
`~/Documents/Нишпорка/projects/sharhoroots`. Для операцій, що потребують
проєкту, використовуйте `sh scripts/nysh.sh --project sharhoroots <команда>`;
для запису безпечніше запускати команду безпосередньо з теки цього проєкту.
Канон статей залишається в цьому сховищі Quartz.
