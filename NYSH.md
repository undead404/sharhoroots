# Нишпорка в цьому проєкті

CLI встановлено через `uv tool install --python 3.12 'nyshporka[app,archives]'` в ізольоване користувацьке середовище. Команда `nysh` доступна в PATH; перевірка версії — `nysh version`.

Робочий простір: `~/Documents/Нишпорка`, поза сховищем Quartz. Для команд із цього репозиторію використовуйте обгортку, яка явно обирає простір:

```sh
sh scripts/nysh.sh info
sh scripts/nysh.sh op workspace.info
sh scripts/nysh.sh doctor --json
sh scripts/nysh.sh catalog list
```

Змінна `NYSHPORKA_WORKSPACE` перевизначає шлях обгортки. Доступ Codex до вибраного простору налаштовано в `.codex/config.toml`; зміна застосовується в новій сесії.

Встановлено набір `catalog`: каталоги й архівні інструменти. Рушії HTR та ваги моделей не встановлено; їх налаштовують окремо перед читанням сканів. Дані справ, скани й результати читання зберігайте в просторі Нишпорки, а не в `content/`. Для цього сховища не запускайте `nysh site build`: сайт збирає Quartz.

Локальні скіли містяться в `.agents/skills/`. Під час ініціалізації Nysh оновлює керовані файли, зберігаючи змінені вручну. Не використовуйте `nysh skills install --force`: проєкт має власні правила. Архівні робочі процеси виконуйте за `AGENTS.md` та відповідним скілом.

Офіційна інструкція: [встановлення Нишпорки](https://nyshporka.online/docs/install/).
